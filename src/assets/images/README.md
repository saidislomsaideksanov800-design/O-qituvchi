# Images

Drop your photos here, then write the file name in the matching `src/data/*.js` file.

| File (suggested name) | Where it is used | Data field | Size / ratio |
| --- | --- | --- | --- |
| `portrait.webp` | Hero portrait | `hero.portrait` in `profile.js` | 4:5, at least 880×1100 |
| `about.webp` | About photo | `about.photo` in `profile.js` | 4:5, at least 960×1200 |
| `video-1.webp` … | Own video thumbnails (optional) | `thumbnail` in `videos.js` | 16:9, 1280×720 |
| `avatar-1.webp` … | Testimonial avatars (optional) | `avatar` in `testimonials.js` | 1:1, 96×96 |

Use **WebP** (or AVIF) and keep each file under ~200 KB.
Free tool to convert and compress: https://squoosh.app
