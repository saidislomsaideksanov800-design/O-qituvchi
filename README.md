# Darsim — уроки и тесты для 1–6 классов

Обучающая платформа для самостоятельной работы дома (русские школы Узбекистана).
Ребёнок изучает урок, проходит тест, и **только после теста (≥ 80 %) открывается следующий урок**.

Сайт: https://o-qituvchi.vercel.app · Автор: Saideksanov Saidislom Saydullo o'g'li

---

## Запуск

```bash
npm install      # один раз
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в папке dist
```

Сайт публикуется автоматически: каждый `git push` в ветку `main` → Vercel пересобирает сайт.

## Как добавить или изменить урок

Все уроки лежат в `src/data/curriculum/`:

| Файл | Класс |
| --- | --- |
| `grade1.js` … `grade6.js` | 1–6 классы |
| `index.js` | названия предметов и инструкция по формату |

В каждом файле 4 предмета: `math`, `russian`, `reading`, `nature`. Урок выглядит так:

```js
{
  title: 'Название урока',
  goal: 'Что ученик научится делать',
  body: [
    { t: 'rule', text: 'Правило' },                    // выделенное правило
    { t: 'p', text: 'Обычный абзац' },
    { t: 'ex', title: 'Пример', lines: ['строка 1', 'строка 2'] },
    { t: 'list', items: ['пункт 1', 'пункт 2'] },
    { t: 'quote', lines: ['строки стихотворения'], by: 'Автор' },
  ],
  quiz: [
    // ПЕРВЫЙ ответ — правильный. На экране ответы перемешиваются.
    { q: 'Вопрос?', a: ['правильный', 'неверный', 'неверный'], why: 'Пояснение (необязательно)' },
  ],
}
```

Новый урок добавляется в конец массива предмета — он автоматически станет следующим и будет закрыт, пока не пройден предыдущий.

## Правила платформы

- Порог прохождения теста — `passRatio` в `src/data/site.js` (сейчас 0.8 = 80 %).
- Прогресс хранится в браузере (localStorage) на этом устройстве.
- Тест можно пересдавать сколько угодно раз; вопросы и ответы каждый раз перемешиваются.

## Тексты интерфейса (RU / UZ)

`src/lib/i18n.jsx` — все подписи на русском и узбекском. Уроки — на русском (язык обучения).

## Дизайн

Цвета, шрифт, радиусы — `tailwind.config.js`. Иконки — `src/assets/icons/glyphs.js`.
Стиль вдохновлён государственными сервисными порталами, но **без их логотипов, гербов и названий**: Darsim — частный проект, это указано в подвале сайта.

## Сейчас в базе

72 урока (6 классов × 4 предмета × 3 урока), 360 тестовых вопросов. Темы соответствуют типичной программе — сверяйте с календарным планом учителя.
